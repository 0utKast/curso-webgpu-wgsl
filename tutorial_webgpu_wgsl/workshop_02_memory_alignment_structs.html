🗺️ Mapa de Memoria Física (Palabras de 16 Bytes)

Cada fila representa una palabra de 128 bits (16 bytes) leída por la GPU en un único ciclo de reloj.

Diagnóstico: Los campos respetan el alineamiento de 16 bytes. El struct mide exactamente 48 bytes (3 palabras GPU).

📄 Código WGSL del Compute Shader

// Estructura física con reglas de alineamiento del W3C
struct ParticulaFisica {
    posicion:  vec4<f32>, // Offset  0..15 (Alineamiento: 16 bytes)
    velocidad: vec4<f32>, // Offset 16..31 (Alineamiento: 16 bytes)
    masa:      f32,       // Offset 32..35 (Alineamiento:  4 bytes)
    vida:      f32,       // Offset 36..39 (Alineamiento:  4 bytes)
    id_tipo:   u32,       // Offset 40..43 (Alineamiento:  4 bytes)
    // ⚠️ PADDING IMPLÍCITO: Bytes 44..47 reservados para completar múltiplo de 16 bytes
};

@group(0) @binding(0) var<storage, read_write> particulas: array<ParticulaFisica>;

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let i = global_id.x;
    if (i >= arrayLength(&particulas)) { return; }

    // Actualización cinemática masiva paralela en GPU
    let dt = 0.016f; // 16ms (60 FPS)
    particulas[i].posicion = particulas[i].posicion + particulas[i].velocidad * dt;
    particulas[i].vida = particulas[i].vida - dt;
}
