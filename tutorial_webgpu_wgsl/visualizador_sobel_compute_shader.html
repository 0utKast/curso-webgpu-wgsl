Visión Global del Compute Shader de Convolución 2D

Este shader procesa cada píxel de forma masivamente paralela en la GPU, muestreando los 8 vecinos contiguos mediante coordenadas discretas de enteros y aplicando las matrices diferenciales de Sobel.

1// ============================================================================
2// COMPUTE SHADER: Filtro de Convolución 2D de Sobel en WGSL
3// ============================================================================
4
5// Entrada: Textura 2D muestreable (Solo Lectura)
6@group(0) @binding(0) var textura_entrada: texture_2d<f32>;
7
8// Salida: Textura de Almacenamiento (Escritura directa de Píxeles)
9@group(0) @binding(1) var textura_salida: texture_storage_2d<rgba8unorm, write>;
10
11// Función auxiliar: Extrae la luminancia perceptual ITU-R BT.601 de un píxel
12fn obtener_luminancia(coords_enteras: vec2<i32>, dimensiones: vec2<i32>) -> f32 {
13 // Tratamiento de bordes: Clamping manual para evitar lecturas fuera de memoria
14 let coords_seguras: vec2<u32> = vec2<u32>(
15 clamp(coords_enteras, vec2<i32>(0, 0), dimensiones - vec2<i32>(1, 1))
16 );
17
18 // textureLoad: lectura sin interpolación ni filtrado lineal
19 let color: vec4<f32> = textureLoad(textura_entrada, coords_seguras, 0u);
20 return 0.299 * color.r + 0.587 * color.g + 0.114 * color.b;
21}
22
23// Configuración del Workgroup: 16x16 = 256 hilos por bloque de trabajo
24@compute @workgroup_size(16, 16)
25fn cs_sobel(
26 @builtin(global_invocation_id) global_id: vec3<u32>
27) {
28 let dims_u: vec2<u32> = textureDimensions(textura_entrada);
29 let dims: vec2<i32> = vec2<i32>(dims_u);
30 let x: i32 = i32(global_id.x);
31 let y: i32 = i32(global_id.y);
32
33 // Guarda de límites: Evitar que hilos sobrantes escriban fuera de la imagen
34 if (x >= dims.x || y >= dims.y) {
35 return;
36 }
37
38 // 1. Lectura de la vecindad 3x3 de luminancia (9 lecturas independientes a VRAM)
39 let l00 = obtener_luminancia(vec2<i32>(x - 1, y - 1), dims);
40 let l10 = obtener_luminancia(vec2<i32>(x, y - 1), dims);
41 let l20 = obtener_luminancia(vec2<i32>(x + 1, y - 1), dims);
42
43 let l01 = obtener_luminancia(vec2<i32>(x - 1, y), dims);
44 // El píxel central (x, y) no interviene en las matrices clásicas de Sobel
45 let l21 = obtener_luminancia(vec2<i32>(x + 1, y), dims);
46
47 let l02 = obtener_luminancia(vec2<i32>(x - 1, y + 1), dims);
48 let l12 = obtener_luminancia(vec2<i32>(x, y + 1), dims);
49 let l22 = obtener_luminancia(vec2<i32>(x + 1, y + 1), dims);
50
51 // 2. Convolución con el Kernel Horizontal (Gx)
52 // Kx = [-1, 0, +1; -2, 0, +2; -1, 0, +1]
53 let gx: f32 = (-1.0 * l00) + (1.0 * l20) +
54 (-2.0 * l01) + (2.0 * l21) +
55 (-1.0 * l02) + (1.0 * l22);
56
57 // 3. Convolución con el Kernel Vertical (Gy)
58 // Ky = [-1, -2, -1; 0, 0, 0; +1, +2, +1]
59 let gy: f32 = (-1.0 * l00) + (-2.0 * l10) + (-1.0 * l20) +
60 ( 1.0 * l02) + ( 2.0 * l12) + ( 1.0 * l22);
61
62 // 4. Magnitud Euclídea del Gradiente Total: sqrt(Gx² + Gy²)
63 let magnitud: f32 = sqrt(gx * gx + gy * gy);
64
65 // 5. Empaquetado visual del color: Aristas blancas sobre fondo negro
66 let color_borde = vec4<f32>(magnitud, magnitud, magnitud, 1.0);
67
68 // 6. Escritura directa en la Storage Texture (VRAM)
69 textureStore(textura_salida, vec2<u32>(global_id.xy), color_borde);
70}
📐 Matrices Kernel de Sobel 3×3 (1968)
Kx (Gradiente Horizontal)
-10+1
-20+2
-10+1
Ky (Gradiente Vertical)
-1-2-1
000
+1+2+1
Gx = (l20 - l00) + 2·(l21 - l01) + (l22 - l02)
Gy = (l02 - l00) + 2·(l12 - l10) + (l22 - l20)
🔬 Fórmulas del Shader
1. Luminancia Perceptual ITU-R BT.601:
Y = 0.299·R + 0.587·G + 0.114·B
2. Magnitud Euclídea del Borde:
|∇I| = √( Gx² + Gy² )
3. Tratamiento Seguro de Bordes (Clamping):
coords = clamp(c, vec2(0,0), dims - 1)
