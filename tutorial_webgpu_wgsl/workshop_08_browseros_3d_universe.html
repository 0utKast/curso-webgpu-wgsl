Diagnóstico de Silicio Activo

El silicio ejecuta el pipeline de renderizado completo: los vértices se proyectan mediante la matriz MVP en el Vertex Shader, el Rasterizador calcula la cobertura de píxeles e interpola normales en coordenadas homogéneas, y el Fragment Shader calcula el vector medio de Blinn-Phong y la componente especular conservando 60 FPS estables.

1. Vertex Fetch & Indexing

Función Fija (Silicio)

Circuitería cableada que lee las posiciones, normales y atributos directamente desde la memoria VRAM sin consumir ciclos de CPU ni instrucciones de sombreado. Se programa de forma inmutable mediante la propiedad buffers: [{ arrayStride, attributes }] en createRenderPipeline.

Entrada: GPUBufferUsage.VERTEX | arrayStride = 44 bytes

2. Vertex Shader

Programable (@vertex)

Las ALUs del chip ejecutan nuestro código WGSL en paralelo para cada vértice. Transforma las coordenadas de espacio local a Espacio de Recorte (Clip Space) multiplicando por la matriz Model-View-Projection (MVP). Emite obligatoriamente @builtin(position) vec4<f32>.

WGSL: out.clipPos = uniforms.mvp * vec4(in.pos, 1.0);

3. Primitive Assembly & Culling

Función Fija (Silicio)

Agrupa los vértices procesados en triángulos (triangle-list). Aplica el descarte de caras traseras (Backface Culling) comprobando la orientación de los vértices (sentido antihorario ccw) y recorta físicamente los triángulos que sobresalen del volumen de visión antes de gastar ancho de banda de rasterización.

Configuración: cullMode: 'back', frontFace: 'ccw'

4. Rasterizador & Baricéntricas

Función Fija (Silicio)

El corazón analógico del renderizado: proyecta los triángulos a píxeles de pantalla evaluando funciones de arista en silicio a velocidades deslumbrantes. Para cada fragmento cubierto, interpola los atributos de vértice mediante derivadas baricéntricas corregidas por perspectiva dividiendo entre la coordenada homogénea w.

Física: Coordenadas Baricéntricas λ₀, λ₁, λ₂ con corrección hiperbólica 1/w

5. Early-Z Oclusion Culling

Función Fija (Silicio)

Optimización crítica de silicio: antes de ejecutar el costoso Fragment Shader, el hardware compara la profundidad Z del fragmento contra el búfer de profundidad (Depth Buffer). Si el píxel ya está tapado por una superficie más cercana, se aborta inmediatamente, ahorrando el 100% de los ciclos de sombreado.

Hardware: Hierarchical-Z (Hi-Z) y comparación depthCompare: 'less'

6. Fragment Shader

Programable (@fragment)

Calcula el color final de cada píxel que superó las pruebas de visibilidad. En nuestro taller evalúa la iluminación física PBR, calcula la reflectancia Blinn-Phong, muestrea texturas mediante TFUs o emite diagnósticos de normales y profundidad linealizada.

WGSL: fn fs_main(in: VertexOutput) -> @location(0) vec4<f32>

7. Unidades ROP & Alpha Blending

Función Fija (Silicio)

Las Render Output Units escriben los valores finales en la memoria VRAM del framebuffer. Realizan la prueba de profundidad final (Late-Z) si el shader modificó la posición, escriben en el Depth Buffer si depthWriteEnabled: true y ejecutan las ecuaciones de mezcla alfa cableadas.

Salida: Formato nativo Swapchain (BGRA8Unorm / RGBA8Unorm)
WGSL (Compute Shader)
// ============================================================================
// COMPUTE SHADER: Simulación Dinámica de Partículas (Compute-to-Render)
// ============================================================================
struct Particle {
  pos: vec3<f32>,
  pad0: f32,
  vel: vec3<f32>,
  pad1: f32,
  color: vec4<f32>,
};

@group(0) @binding(0) var<storage, read_write> particles: array<Particle>;

struct SimUniforms {
  dt: f32,
  gravity: f32,
  damping: f32,
  time: f32,
};
@group(0) @binding(1) var<uniform> sim: SimUniforms;

@compute @workgroup_size(64)
fn cs_main(@builtin(global_invocation_id) id: vec3<u32>) {
  let idx = id.x;
  if (idx >= arrayLength(&particles)) { return; }

  var p = particles[idx];
  let dt = sim.dt;
  
  // Potencial de Plummer suavizado: a = -GM * x / (r^2 + eps^2)^1.5
  let r2 = dot(p.pos.xz, p.pos.xz);
  let eps2 = 0.35;
  let denom = pow(r2 + eps2, 1.5);
  let gm = sim.gravity * 2.2;
  
  // Atracción centrípeta en el plano galáctico X-Z y resorte restaurador en Y
  let accelXZ = -gm * p.pos.xz / denom;
  let accelY = -p.pos.y * 6.0 - p.vel.y * 2.0;
  
  p.vel = vec3<f32>(p.vel.x + accelXZ.x * dt, p.vel.y + accelY * dt, p.vel.z + accelXZ.y * dt);
  p.pos = p.pos + p.vel * dt;
  
  // Escribir directamente en el mismo búfer en VRAM (Compute-to-Render sin ida y vuelta al CPU)
  particles[idx] = p;
}
// ============================================================================
// VERTEX SHADER: Transformaciones Homogéneas MVP y Coordenadas Baricéntricas
// ============================================================================
struct Uniforms {
  mvp: mat4x4<f32>,
  model: mat4x4<f32>,
  normalMat: mat4x4<f32>,
  camPos: vec3<f32>,
  shadingMode: u32, // 0: PBR, 1: Normales, 2: Baricéntricas, 3: Z-Buffer, 4: UV
  lightPos: vec3<f32>,
  roughness: f32,
  nearZ: f32,
  farZ: f32,
  time: f32,
  pad: f32,
};
@group(0) @binding(0) var<uniform> uniforms: Uniforms;

struct VertexInput {
  @location(0) position: vec3<f32>,
  @location(1) normal: vec3<f32>,
  @location(2) uv: vec2<f32>,
  @location(3) barycentric: vec3<f32>,
};

struct VertexOutput {
  @builtin(position) clipPos: vec4<f32>,
  @location(0) worldPos: vec3<f32>,
  @location(1) worldNormal: vec3<f32>,
  @location(2) uv: vec2<f32>,
  @location(3) barycentric: vec3<f32>,
};

@vertex
fn vs_main(in: VertexInput) -> VertexOutput {
  var out: VertexOutput;
  out.clipPos = uniforms.mvp * vec4<f32>(in.position, 1.0);
  out.worldPos = (uniforms.model * vec4<f32>(in.position, 1.0)).xyz;
  out.worldNormal = normalize((uniforms.normalMat * vec4<f32>(in.normal, 0.0)).xyz);
  out.uv = in.uv;
  out.barycentric = in.barycentric;
  return out;
}
// ============================================================================
// FRAGMENT SHADER: Diagnósticos de Silicio y Sombreado Físico
// ============================================================================
@fragment
fn fs_main(in: VertexOutput) -> @location(0) vec4<f32> {
  // 1. MODO NORMALES DE SUPERFICIE: Mapeo de [-1, 1] a [0, 1]
  if (uniforms.shadingMode == 1u) {
    let normColor = in.worldNormal * 0.5 + vec3<f32>(0.5);
    return vec4<f32>(normColor, 1.0);
  }

  // 2. MODO COORDENADAS BARICÉNTRICAS: Malla Wireframe procedimental
  if (uniforms.shadingMode == 2u) {
    let b = in.barycentric;
    let minB = min(min(b.x, b.y), b.z);
    let edge = 1.0 - smoothstep(0.0, 0.04, minB);
    let baseCol = vec3<f32>(b.x, b.y, b.z) * 0.6;
    let finalCol = mix(baseCol, vec3<f32>(0.2, 0.9, 1.0), edge);
    return vec4<f32>(finalCol, 1.0);
  }

  // 3. MODO Z-BUFFER: Linealización de la profundidad no lineal de WebGPU [0, 1]
  if (uniforms.shadingMode == 3u) {
    let z_ndc = in.clipPos.z; // Coordenada de profundidad de pantalla
    let linearZ = (uniforms.nearZ * uniforms.farZ) / 
                  (uniforms.farZ - z_ndc * (uniforms.farZ - uniforms.nearZ));
    let depthNorm = clamp((linearZ - uniforms.nearZ) / 
                          (uniforms.farZ - uniforms.nearZ), 0.0, 1.0);
    return vec4<f32>(vec3<f32>(depthNorm), 1.0);
  }

  // 4. MODO COORDENADAS UV
  if (uniforms.shadingMode == 4u) {
    return vec4<f32>(in.uv.x, in.uv.y, 0.5, 1.0);
  }

  // 0. MODO ILUMINACIÓN PBR / BLINN-PHONG MODULADA POR RUGOSIDAD
  let N = normalize(in.worldNormal);
  let L = normalize(uniforms.lightPos - in.worldPos);
  let V = normalize(uniforms.camPos - in.worldPos);
  let H = normalize(L + V);

  let NdotL = max(dot(N, L), 0.0);
  let NdotH = max(dot(N, H), 0.0);
  let VdotH = max(dot(V, H), 0.0);

  let r = clamp(uniforms.roughness, 0.0, 1.0);
  let smoothness = 1.0 - r;
  let shiny = mix(4.0, 128.0, smoothness * smoothness);
  let specPower = pow(NdotH, shiny);
  let specLobe = specPower * mix(0.35, 1.8, smoothness);

  let F0 = mix(0.04, 0.60, smoothness);
  let fresnel = F0 + (1.0 - F0) * pow(1.0 - VdotH, 5.0);

  let albedo = vec3<f32>(0.22, 0.65, 0.98);
  let diffuseTerm = albedo * NdotL * mix(0.65, 1.15, r);
  let specularTerm = vec3<f32>(1.0, 1.0, 1.0) * specLobe * mix(1.0, fresnel, smoothness);
  let ambientTerm = mix(vec3<f32>(0.03, 0.05, 0.08), vec3<f32>(0.12, 0.16, 0.22), r);

  let color = ambientTerm + diffuseTerm + specularTerm;
  return vec4<f32>(color, 1.0);
}

// ORQUESTACIÓN EN HOST: Sumisión Atómica Compute-to-Render
// ============================================================================

// 1. El búfer de partículas se crea con uso combinado STORAGE | VERTEX
const particleBuffer = device.createBuffer({
  size: PARTICLE_COUNT * 48, // 48 bytes por partícula (pos, vel, color)
  usage: GPUBufferUsage.STORAGE | GPUBufferUsage.VERTEX | GPUBufferUsage.COPY_DST,
});

// 2. En el bucle de renderizado: codificación de ambos pases en un solo encoder
function renderFrame(timestamp) {
  const commandEncoder = device.createCommandEncoder();

  // PASE A: Simulación Física en Compute Shader
  if (!isPaused) {
    const computePass = commandEncoder.beginComputePass();
    computePass.setPipeline(computePipeline);
    computePass.setBindGroup(0, computeBindGroup);
    computePass.dispatchWorkgroups(Math.ceil(PARTICLE_COUNT / 64));
    computePass.end();
  }

  // PASE B: Pipeline Gráfico de Renderizado (Render Pass)
  const renderPass = commandEncoder.beginRenderPass({
    colorAttachments: [{
      view: context.getCurrentTexture().createView(),
      clearValue: { r: 0.04, g: 0.06, b: 0.09, a: 1.0 },
      loadOp: 'clear',
      storeOp: 'store',
    }],
    depthStencilAttachment: {
      view: depthTextureView,
      depthClearValue: 1.0,
      depthLoadOp: 'clear',
      depthStoreOp: 'store',
    },
  });

  renderPass.setPipeline(renderPipeline);
  renderPass.setBindGroup(0, renderBindGroup);
  renderPass.setVertexBuffer(0, particleBuffer); // ¡Lectura directa sin copia!
  renderPass.draw(PARTICLE_COUNT);
  renderPass.end();

  // SUMISIÓN ATÓMICA: La GPU sincroniza ambos pases en hardware nativo
  device.queue.submit([commandEncoder.finish()]);

  requestAnimationFrame(renderFrame);
}
