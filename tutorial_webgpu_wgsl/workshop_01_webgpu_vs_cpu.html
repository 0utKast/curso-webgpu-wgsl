💡 Clave Arquitectónica: ¿Por qué a 1 sola iteración los tiempos son parecidos?

Con 1 sola pasada sobre 1M de elementos (4 MB), el chip GPU termina el cálculo en apenas ~1 ms. Sin embargo, llamar a stagingBuffer.mapAsync() para copiar esos 4 MB de vuelta a la memoria de JavaScript y resolver la promesa añade entre 15 y 18 ms de latencia del bus. En sistemas reales (como redes neuronales de IA o renderizado), los datos nunca salen de la GPU entre capas sucesivas. Aumenta la Intensidad Aritmética a 10 o 30 iteraciones para comprobar cómo la GPU pulveriza a la CPU cuando el cómputo domina sobre la transferencia.

🔍 Inspección del Código del Taller

// Ejecución secuencial en CPU (hilo principal / Event Loop de JavaScript)
const cpuOutput = new Float32Array(size);
const startCpu = performance.now();

// Un único hilo procesa cada elemento uno a uno en serie, repitiendo N iteraciones
for (let i = 0; i < size; i++) {
  let val = inputData[i];
  for (let k = 0; k < iterations; k++) {
    val = Math.sqrt(val) * 2.5 + Math.sin(val);
  }
  cpuOutput[i] = val;
}

const cpuTime = performance.now() - startCpu;
struct Params {
    iterations: u32,
};

@group(0) @binding(0) var<storage, read> inputData: array<f32>;
@group(0) @binding(1) var<storage, read_write> outputData: array<f32>;
@group(0) @binding(2) var<uniform> params: Params;

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let index = global_id.x;
    if (index >= arrayLength(&inputData)) { return; }

    // Miles de hilos ejecutan sus iteraciones en paralelo directamente en el silicio
    var val = inputData[index];
    for (var k = 0u; k < params.iterations; k = k + 1u) {
        val = sqrt(val) * 2.5 + sin(val);
    }
    outputData[index] = val;
}
// 1. Despacho y configuración del pipeline WebGPU en JavaScript
const commandEncoder = device.createCommandEncoder();
const pass = commandEncoder.beginComputePass();
pass.setPipeline(computePipeline);
pass.setBindGroup(0, bindGroup);

// 2. Despachar grupos de trabajo (Workgroups de 64 hilos cada uno)
pass.dispatchWorkgroups(Math.ceil(totalElements / 64));
pass.end();

// 3. Enviar a la GPU y esperar fin de cómputo en hardware
device.queue.submit([commandEncoder.finish()]);
await device.queue.onSubmittedWorkDone(); // ~1 ms de silicio

// 4. Lectura asíncrona hacia memoria de JavaScript (latencia del bus)
await stagingBuffer.mapAsync(GPUMapMode.READ);
